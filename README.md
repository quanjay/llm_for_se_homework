# 水印文件本地应用

一款简单易用的Windows本地水印应用程序，帮助用户快速为单张或批量图片添加文本水印。本应用无需联网，完全在本地运行，保护用户隐私的同时提供高效的水印处理功能。

## 功能特点

- 支持单张或批量导入图片（支持拖拽导入）
- 支持多种图片格式（JPEG, PNG, BMP, TIFF）
- 自定义文本水印内容、样式和位置
- 调整水印透明度、字体大小和颜色
- 九宫格位置预设，一键放置水印
- 实时预览水印效果
- 灵活的导出选项（自定义前缀/后缀，多种格式）
- 水印模板保存和管理（自动加载上次设置）

## 系统要求

- 操作系统：Windows 10及以上版本
- Python 3.9或更高版本
- 显示器：支持高DPI显示

## 安装说明

### 方法一：直接下载可执行文件（推荐）

1. 在[GitHub Releases](https://github.com/YOUR_USERNAME/llm_for_se_homework/releases)页面下载最新版本的`WatermarkApp_release.zip`
2. 解压缩下载的文件
3. 运行解压后文件夹中的`WatermarkApp.exe`

### 方法二：从源代码运行

1. 确保已安装Python 3.8或更高版本
2. 克隆或下载本项目到本地
3. 安装依赖包：
   ```
   pip install -r requirements.txt
   ```
4. 运行主程序：
   ```
   python main.py
   ```

## 使用说明

1. **导入图片**：
   - 点击"导入"按钮选择单张或多张图片
   - 点击"导入文件夹"按钮导入整个文件夹中的图片
   - 直接将图片文件拖拽到应用窗口

2. **设置水印**：
   - 在右侧面板输入水印文本
   - 调整字体大小、颜色和透明度
   - 选择水印位置（九宫格预设位置）

3. **预览效果**：
   - 在中央预览区实时查看水印效果
   - 点击图片列表中的不同图片可切换预览

4. **导出图片**：
   - 点击"导出"按钮
   - 选择输出目录（默认禁止导出到原图片所在文件夹）
   - 设置输出格式（JPEG/PNG）和文件命名规则
   - 确认导出

5. **模板管理**：
   - 点击"保存模板"按钮保存当前水印设置
   - 使用下拉菜单选择已保存的模板
   - 点击"删除模板"按钮删除不需要的模板

## 项目结构

- `main.py`: 程序入口
- `ui/`: 用户界面相关模块
  - `main_window.py`: 主窗口界面
  - `preview_widget.py`: 预览区域组件
  - `image_list_widget.py`: 图片列表组件
  - `export_dialog.py`: 导出设置对话框
- `core/`: 核心功能模块
  - `file_handler.py`: 文件处理模块
  - `watermark.py`: 水印处理模块
  - `config_manager.py`: 配置管理模块
- `resources/`: 资源文件
  - `images/`: 示例图片
  - `images_watermark/`: 水印处理后的图片
- `templates/`: 水印模板存储
