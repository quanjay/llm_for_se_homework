# 水印文件本地应用

一款简单易用的Windows本地水印应用程序，帮助用户快速为单张或批量图片添加文本水印。

## 功能特点

- 支持单张或批量导入图片
- 支持多种图片格式（JPEG, PNG, BMP, TIFF）
- 自定义文本水印内容、样式和位置
- 实时预览水印效果
- 灵活的导出选项
- 水印模板保存和管理

## 安装说明

1. 确保已安装Python 3.8或更高版本
2. 安装依赖包：
   ```
   pip install -r requirements.txt
   ```
3. 运行主程序：
   ```
   python main.py
   ```

## 使用说明

1. 启动程序后，可通过"导入"按钮或拖拽方式导入图片
2. 在右侧面板设置水印文本、样式和位置
3. 在预览区查看水印效果
4. 点击"导出"按钮，选择输出目录和格式，完成水印添加

## 项目结构

- `main.py`: 程序入口
- `ui/`: 用户界面相关模块
- `core/`: 核心功能模块
  - `file_handler.py`: 文件处理模块
  - `watermark.py`: 水印处理模块
  - `config_manager.py`: 配置管理模块
- `resources/`: 资源文件
- `templates/`: 水印模板存储
