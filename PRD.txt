# 图片EXIF时间水印添加工具 - 项目需求规格文档

## 1. 项目概述

### 1.1 项目背景
用户需要一个简单的命令行工具，能够读取图片的EXIF信息中的拍摄时间，并将其作为水印添加到图片上，以便于图片整理和归档。

### 1.2 项目目标
开发一个Python命令行程序，能够批量处理指定目录下的图片，提取EXIF信息中的拍摄时间，并根据用户设置的参数将时间信息作为水印添加到图片上。

## 2. 功能需求

### 2.1 基本功能
1. 用户输入一个图片文件路径
2. 程序读取该路径下所有图片文件的EXIF信息中的拍摄时间（年月日）
3. 程序将拍摄时间作为水印添加到图片上
4. 程序将添加水印后的图片保存到新目录中

### 2.2 详细功能描述

#### 2.2.1 输入处理
- 程序接受用户输入的图片目录路径
- 程序验证路径的有效性，并检查目录是否存在
- 程序识别目录下的所有图片文件（支持常见图片格式如JPG、PNG等）

#### 2.2.2 EXIF信息提取
- 程序读取每张图片的EXIF信息
- 从EXIF信息中提取拍摄时间（年月日）
- 对于没有EXIF信息或拍摄时间信息的图片，程序应提供适当的错误处理

#### 2.2.3 水印设置
- 用户可以设置水印文本的字体大小
- 用户可以设置水印文本的颜色
- 用户可以设置水印在图片上的位置（左上角、居中、右下角等）

#### 2.2.4 水印添加
- 程序将提取的拍摄时间（年月日）作为文本水印
- 根据用户设置的参数（字体大小、颜色、位置）将水印添加到图片上
- 确保水印清晰可见但不过分影响原图片的视觉效果

#### 2.2.5 文件保存
- 程序在原目录下创建一个新的子目录，命名为"原目录名_watermark"
- 程序将添加水印后的图片保存到新目录中
- 保存的图片应保持原图片的质量和分辨率

## 3. 技术要求

### 3.1 开发环境
- 编程语言：Python 3.x
- 操作系统：跨平台（Windows、macOS、Linux）

### 3.2 依赖库
- 图片处理：Pillow (PIL)
- EXIF信息提取：Pillow或exifread
- 命令行参数解析：argparse

### 3.3 性能要求
- 程序应能高效处理大量图片
- 程序应具有良好的错误处理机制
- 程序应提供清晰的进度反馈

## 4. 用户界面

### 4.1 命令行界面
程序通过命令行界面与用户交互，接受以下参数：
- 必选参数：图片目录路径
- 可选参数：
  - 字体大小（默认值：20）
  - 字体颜色（默认值：白色）
  - 水印位置（默认值：右下角）
  - 帮助信息

### 4.2 输出信息
程序应提供以下输出信息：
- 处理进度（如：已处理x张，共y张）
- 成功/失败信息
- 最终输出目录路径

## 5. 示例用法

```
python watermark.py /path/to/images --size 24 --color red --position bottom-right
```
